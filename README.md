This project analyzes vaccination coverage, disease incidence, reported cases, vaccine introduction, and vaccination schedules using:

* Python
* SQL
* Power BI

Objectives

* Analyze vaccination trends and coverage.
* Study vaccination and disease incidence.
* Compare demographic groups.
* Identify coverage gaps.
* Create interactive Power BI dashboards.

Dataset

The project uses five datasets:

* Coverage
* Incidence Rate
* Reported Cases
* Vaccine Introduction
* Vaccine Schedule

Note: The dataset is synthetic and created for academic analysis. It is not official WHO data.# Vaccination-
